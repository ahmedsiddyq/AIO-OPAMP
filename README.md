# AIO OP-AMP

All-in-one operational-amplifier electronics project.

## Overview
This repository contains the schematic, PCB, and development files for a custom analog electronics design based around operational-amplifier circuits.

## Focus
- Analog signal conditioning
- Op-amp circuits
- PCB design
- Power supply and signal integrity
- Hardware prototyping

## Tools
- KiCad
- Analog electronics test equipment
